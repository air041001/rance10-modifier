# 安装环境适配

日文原版作为另一套安装环境样本，用来发现对作者本机文件、路径和进度的依赖。
程序不通过分别添加中文版、日文版文件白名单实现适配。

## 判断方式

| 功能 | 使用者本机的数据依据 |
| --- | --- |
| 卡牌图鉴 | 本机EX中的卡表、技能表、人物资料与资源归档 |
| 存档加卡与培养 | 存档实际字段、类型、数组及相关游戏方法的规则 |
| 实时餐券与部队点数 | 本机AIN中的全局对象、成员名称和类型；运行引擎中的实际对象 |
| 战后餐券人物 | 本机AIN中的筛选方法、调用方法与局部对象类型；当前游戏持有的人物和故事引用 |

实时组件从加载后的程序映像识别C++对象类型，取得实际位置。
成员位置、全局编号、方法编号与筛选函数位置从本机AIN推导；不回退到作者的固定地址。
文件摘要用于确认缓存和运行脚本属于所选游戏，文件与作者不同不会直接禁用功能。

餐券故事筛选按指令及符号含义核对，允许翻译、地址、编号变化。
实际规则或对象类型改变时，只报告相关功能需要适配。
餐券与点数连接不要求存在人物图鉴、特定卡牌、旧缓存或新保存的存档。

中文和日文编码由本机图鉴资料识别。资源目录名称直接对照归档内容，
避免把文字编码当成卡面目录名称，支持汉化文字与原版资源目录混用。
存档目录根据所选游戏的AliceStart.ini及实际目录识别，手动选择的自定义目录保留。
新人物的回放和餐券事件路径取自本机初始化方法，避免根据语言猜测部分翻译版本的键名。
