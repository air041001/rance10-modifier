# 兰斯10修改器

一个本地 Windows 工具，主要用于卡牌收集、人物培养，以及减少重复刷取和 SL 带来的时间消耗。

当前版本：**v1.3.4 预览版**

## 下载与使用

从 [Releases](https://github.com/air041001/rance10-modifier/releases) 下载最新 Windows ZIP，**完整解压**后运行 `兰斯10修改器.exe`，无需安装 Python。

首次使用打开 **设置与图鉴**：

1. 选择包含 `Rance10.exe` 的游戏目录，并确认存档目录。
2. 如需使用卡牌图鉴，点击 **从官方源下载并准备**。首次准备需要联网。
3. 也可以自行选择官方 [alice-tools 0.13.0](https://github.com/nunuhara/alice-tools/releases/tag/0.13.0) 的 `alice.exe` 离线准备。
4. 图鉴数据和卡面从用户自己的游戏生成，仓库和发布包不包含游戏素材。

更换游戏版本或补丁后，请重新准备图鉴。若某项功能提示不兼容，可在设置中使用 **复制兼容信息** 反馈；内容不包含存档和个人路径。

## 功能

| 功能 | 使用方式 | 生效方式 |
| --- | --- | --- |
| 餐券 | 按需补满 3 张，保留游戏原上限 | 运行中的游戏即时修改 |
| 部队点数 | 增加 5 点或设置总点数（含已用点数，最多 100，只增不减） | 即时修改 |
| 卡牌图鉴 | 按类型、出场范围、阵营、稀有度等筛选，查看卡面、说明和技能 | 本地查看 |
| 卡牌扩充 | 多选卡牌或补到目标数量，支持人物、通用和物品卡 | 自动备份后修改手动存档，重新读档生效 |
| 人物★等级 | 提高已持有人物的培养★，最高 200；同人物不同卡牌版本共享 | 自动备份后修改手动存档，重新读档生效 |
| 同卡强化 | 提高所选卡牌版本的重复强化，最高 +10；不增加卡牌总数 | 自动备份后修改手动存档，重新读档生效 |
| 餐券故事查看 | 查看人物 A/B/C 故事进度及原始剧情条件 | 只读 |
| 记录与备份 | 查看操作记录、打开原档备份 | 用于回退 |

### 卡牌范围

当前图鉴可读取中文及日文 1.04 卡表中的 984 条未删除正式卡，包括：

- 人物卡 662 条
- 通用卡 145 条
- 物品卡 177 条
- 第一部及特殊范围 857 条
- 第二部 127 条

攻略中的正常收集总数与游戏表正式条目口径并不完全相同，因此工具按本机游戏实际卡表显示，不为了匹配攻略数字隐藏卡牌。

物品卡使用对应卡框、说明与共享物品★。缺少角色记录时，会按游戏现有结构补充角色及相关记录。

“选卡补到目标”优先用于普通 Lv 版本；特殊版本建议手动选择。添加卡牌不会修改剧情解锁，也不保证绕过关卡本身的其他条件。

## 使用注意

- 加卡或培养前，请先在游戏中保存当前进度，再在工具中刷新并选择对应的手动存档。
- 修改完成后，请回到游戏的读档菜单重新读取该存档，不要从修改前仍停留的旧游戏画面再次保存覆盖结果。
- 人物★与卡名中的 `LvXX` 不是同一数值；提高★可能影响部分卡牌的掉落条件。
- 餐券故事页面目前只查看故事进度和条件，不修改故事状态，也不能指定下一次候选人物。
- 修改前会自动备份原存档。

## 兼容性

存档编辑与实时内存修改采用不同的兼容判断：

- **卡牌图鉴、卡牌扩充、人物培养**：按本机游戏数据和实际存档结构检查，不要求 `Rance10.exe`、`Rance10.ain`、`Rance10EX.ex` 三个文件完全相同。
- **实时餐券和部队点数**：依赖游戏运行时内存布局，目前只支持已验证的 EXE/AIN 版本。实时连接失败不会影响存档类功能。
- 当前支持第一部十阵营的 v8 存档。
- 图鉴支持中文 CP936 与日文 CP932 数据。
- 特殊卡和不同改版的边缘情况不保证全部经过逐卡、逐路线实际游戏验证。

更详细的覆盖与验证记录见 [卡牌覆盖核查](docs/CARD_COVERAGE_AUDIT.md) 和 [开发计划](docs/NEXT_STAGE.md)。

## 本机数据与恢复

- 配置、图鉴缓存和记录：Windows“文档”中的 `Rance10Modifier`
- 默认存档位置：Windows“文档”下的 `AliceSoft\兰斯10\SaveData`，也可手动选择
- 原档备份：所选 `SaveData` 上一级的 `修改前备份`
- 恢复时先关闭游戏，再按备份目录中的 `恢复说明.txt` 操作
- 更新程序时完整解压新版本即可，配置和图鉴缓存会继续保留

仓库及下载包不包含游戏程序、卡牌素材、游戏数据库、用户存档、个人配置与操作记录。

第三方组件说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 开发与构建

源代码位于 `app`，实时数值组件位于 `native`。

需要 Windows、Python 3.10 x64，以及系统 .NET Framework C# 编译器。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\build.py
.\.venv\Scripts\python.exe app\main.py
```

输出目录为 `dist\Rance10Modifier`，发布 ZIP 和校验文件位于 `release`。

运行基础检查：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

开发时可通过 `RANCE10_MODIFIER_DATA_DIR` 指定独立的数据目录。
