# 兰斯10修改器

一个 Windows 桌面工具，让你少刷卡、少刷餐券，按自己的节奏游玩《兰斯10》。

支持游玩中补餐券、增加部队点数、指定餐券故事人物，以及带卡面预览的卡牌扩充和人物培养。

当前版本：**v1.4.0**

## 下载

前往 [Releases](https://github.com/air041001/rance10-modifier/releases) 下载最新 Windows ZIP，完整解压后打开 **兰斯10修改器.exe**。

无需安装 Python。分享给朋友时，请发送完整 ZIP。

## 能做什么

| 功能 | 操作 |
| --- | --- |
| 补餐券 | 游戏运行时，一键补满3张 |
| 部队加成点数 | 增加5点，或设置包含已用点数的总额 |
| 指定餐券故事人物 | 选择已持有的人物，让其成为战后的餐券候选；看完后可以换人继续 |
| 卡牌扩充 | 查看卡面、技能和物品说明，按类型、阵营、稀有度筛选，多选添加或补到目标张数 |
| 人物培养★ | 提高人物的实际培养等级，同一人物的不同版本共享 |
| 同卡强化 | 提高所选卡牌版本的重复强化 |
| 备份与恢复 | 存档修改前自动备份，在“记录与备份”中打开原档 |

卡牌列表包含人物、通用卡、物品卡、特级、超稀有及裸卡，并提供第一部和第二部范围筛选。
人物培养★与卡名里的 `LvXX` 不同。

## 第一次使用

1. 打开 **设置与图鉴**，选择含有 `Rance10.exe` 的游戏目录。
2. 确认存档目录，点击 **保存并检查**。
3. 点击 **从官方源下载并准备**，从自己的游戏生成卡牌图鉴、图片和人物资料。
   已有 [alice-tools 0.13.0](https://github.com/nunuhara/alice-tools/releases/tag/0.13.0) 的用户，也可选择本地 `alice.exe` 离线准备。

旧用户更新时完整解压新包即可，配置和图鉴会继续使用。更换游戏目录或补丁后，重新准备该游戏的图鉴。

## 游玩中修改

### 餐券与部队点数

启动游戏并载入进度，在修改器中点击 **补满3张餐券**、**增加5点** 或 **设置总点数**，无需先保存。
若游戏菜单仍显示旧值，重新打开对应菜单。

### 餐券小故事

先在游戏中读取要玩的存档，再在 **人物培养** 页面点击 **读取当前游戏**，选择有未完成故事的人物，点击 **指定战后餐券人物**。

请在战后候选生成前指定。已经显示出来的名单会在游戏下次生成候选时更新。
观看后可重新指定另一个人物，需要时补满餐券继续刷。故事仍按游戏的剧情条件和A/B/C顺序推进。

点击 **取消指定** 恢复随机候选；读档、该人物故事全部完成或关闭修改器也会结束指定。
再次读档后，请重新读取当前游戏并指定人物。

### 卡牌与培养

先在游戏中保存当前进度，再在修改器里刷新、选择该手动存档，添加卡牌或提高培养数值。
完成后，在游戏中重新读取修改后的存档，避免从修改前的游戏画面再次保存覆盖结果。

培养★最高200；同卡强化最高+10；部队总点数最高100，只增不减。

## 支持与适配

- Windows 10/11 x64，系统 .NET Framework 4.x。
- 图鉴与存档功能读取本机游戏数据，识别中文和日文内容，无需确认汉化组名称。
- 实时功能从本机脚本取得字段和函数位置，并识别实际运行对象，适应翻译、文件指纹与位置变化，不要求与作者的游戏文件相同。
- 不同改版改变了相关结构时，界面会提示需要适配的具体功能；可以在设置中 **复制兼容信息** 反馈。

游戏与修改器应以相同权限运行。

## 数据位置

配置、图鉴和记录保存在“文档”中的 `Rance10Modifier` 文件夹。
存档备份位于所选 `SaveData` 上一级的 `修改前备份` 文件夹，内附恢复说明。

下载包不包含游戏、卡面素材或用户存档；图片从使用者自己的游戏生成。

## 开发

源码：`app` 为桌面界面与存档处理，`native` 为实时修改组件。封装后仍可继续开发。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app\main.py
.\.venv\Scripts\python.exe scripts\build.py
.\.venv\Scripts\python.exe -m unittest discover -s tests -q
```

构建产物位于 `dist\Rance10Modifier`，分享包位于 `release`。
开发时可通过 `RANCE10_MODIFIER_DATA_DIR` 指定独立的数据目录。
