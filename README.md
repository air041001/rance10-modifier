# 兰斯10修改器

一个本地 Windows 工具，整合餐券、部队加成点数与可选卡牌扩充。

## 下载与使用

从 [Releases](https://github.com/air041001/rance10-modifier/releases) 下载最新 Windows ZIP，
**完整解压**后打开 `兰斯10修改器.exe`，无需安装 Python。请分享完整 ZIP。

首次使用打开 **设置与图鉴**：

1. 选择含 `Rance10.exe` 的游戏目录，确认存档目录，点击 **保存并检查**。
2. 游戏运行时可直接修改餐券和部队点数。
3. 需要卡牌图鉴时，点击 **从官方源下载并准备**；首次需要联网。
   也可选择官方 [alice-tools 0.13.0](https://github.com/nunuhara/alice-tools/releases/tag/0.13.0)
   的 `alice.exe`，使用本地组件离线准备。组件二进制按 SHA-256 核对。
4. 图鉴从自己的游戏生成，准备完成后即可查看卡面与技能。

## 功能

| 功能 | 使用方式 | 生效方式 |
| --- | --- | --- |
| 餐券 | 按需补满 3 张，保留游戏原上限 | 运行中的游戏即时修改 |
| 部队点数 | 增加 5 点或设置总点数（含已用点数，最多 100，只增不减） | 即时修改，已有加成保留 |
| 卡牌扩充 | 搜索、阵营/稀有度筛选、卡面/技能预览、多选与补到目标 | 备份后修改手动存档，重新读档生效 |
| 记录与备份 | 查看操作记录、打开原档备份 | 原档和恢复说明可用于回退 |

餐券不要求先保存。若图标尚未刷新，重新打开游戏的对应菜单。
加卡时需先保存当前进度，刷新目标手动存档，再点击 **备份并添加**。

图鉴包含本适配版本的 455 张第一部、非裸卡牌；普通、特级、超稀有由游戏表定义。
可添加范围取决于所选存档已有的角色记录和技能适配情况。缺失角色记录的卡仍可查看，
但不能添加。本工具不创建角色、不修改剧情解锁，不保证绕过关卡的全部条件。
“选卡补到目标”只建议普通 Lv 版本；特殊版本需手动选择。

## 支持范围与验证

- Windows 10/11 x64；运行组件使用系统 .NET Framework 4.x。
- 当前仅适配一套已验证的中文版游戏文件，按三个文件的 SHA-256 严格检查。
  不同汉化、补丁或版本会停止修改，具体指纹见 [`app/game_profile.py`](app/game_profile.py)。
- 普通版玛丽斯/卡绯添加，以及 189 → 200 张扩充，已有实际游戏读档与编队验证。
- 特殊卡批量添加完成了存档重建检查，但**没有逐卡、逐路线完成游戏战斗验证**。
- 发布应用在本机 Windows 11 完成独立启动、中文路径移动、图鉴与数值读取检查；
  尚未在另一台电脑完成实际游戏测试。应用未进行代码签名。
- 修改前自动备份；拒绝自动存档、已持有卡、重复选择、未处理宝箱卡与已变化的源存档。
- 内存操作每次重新定位，并限制为已验证字段。游戏与工具应以相同权限运行。

## 本机数据与恢复

- 配置、图鉴缓存和记录：`%LOCALAPPDATA%\Rance10Modifier`。
- 默认通过 Windows 的“文档”位置查找 `AliceSoft\兰斯10\SaveData`，可以手动改选。
- 原档备份：所选 `SaveData` 上一级的 `修改前备份`，每次操作独立保存。
- 恢复时先关闭游戏，按备份内的 `恢复说明.txt` 复制原档。
- 更新时完整解压新包，配置与图鉴会继续使用。程序目录可以移动。

仓库及下载包不包含游戏程序、卡牌素材、游戏数据库、用户存档、个人配置与记录。
有关第三方组件见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 继续开发与构建

封装不会影响后续开发。源代码位于 `app`，实时数值组件在 `native`；修改后重新构建即可。

需要 Windows、Python 3.10 x64，以及系统 .NET Framework C# 编译器。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe scripts\build.py
.\.venv\Scripts\python.exe app\main.py
```

输出目录为 `dist\Rance10Modifier`，分享 ZIP 和校验文件在 `release`。
构建不需要游戏或 alice-tools。图鉴只在用户选择准备后生成。

基础检查：

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

开发用 `RANCE10_MODIFIER_DATA_DIR` 可覆盖个人数据目录，便于隔离测试。
这不改变游戏兼容检查，也不允许修改未适配版本。
